# ORSM MkDocs starter

Copy `docs/` and `mkdocs.yml` into the root of your existing
`~/projects/orsm` repository.

Before replacing anything, make a backup or commit your current working
state.

Then run:

    source .venv/bin/activate
    mkdocs serve

The Evidence Model contains a clearly labelled proposed ORSM 2.1
evidence hierarchy. The worked example is intentionally left as a
scaffold because the source drafts do not contain enough detailed
findings to populate a full case study without inventing material.
