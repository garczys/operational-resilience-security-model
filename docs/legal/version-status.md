# Version and Publication Status

## Current Version

**ORSM 2.1**

**Publication Status:** Public Draft

The Operational Resilience Security Model is currently being refined as an openly published architectural assurance framework.

ORSM 2.1 represents the current public development baseline.

The framework may continue to evolve as assessment methods, evidence models, metrics, worked examples and practical guidance are developed and tested.

## Public Draft Status

A **Public Draft** is considered suitable for review, discussion and practical evaluation, but should not be interpreted as an immutable or formally standardised specification.

Users of ORSM should therefore:

- identify the version used when referencing the framework;
- consider the publication status when applying assessment outcomes;
- retain appropriate evidence supporting architectural decisions;
- apply professional judgement when interpreting ORSM findings; and
- check for later revisions where material decisions depend upon the framework.

## Versioning Approach

ORSM uses version numbers to distinguish material framework changes.

### Major versions

Major versions indicate significant changes to the structure, philosophy or assessment model.

Example:

`ORSM 3.0`

### Minor versions

Minor versions indicate refinements, additional guidance, improved assessment methods, supporting resources or clarification that does not fundamentally replace the framework.

Example:

`ORSM 2.1`

## Change Management

Changes to ORSM should be maintained through the project's version-controlled source repository.

Where practical, significant revisions should identify:

- what changed;
- why the change was made;
- which sections were affected; and
- whether assessment interpretation has materially changed.

## Current Position

ORSM 2.1 should be treated as:

**An evolving public architectural assurance framework intended to support proportionate, sustainable, recoverable and operationally resilient security architecture.**
