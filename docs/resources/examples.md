# Worked Examples

The source framework proposes a worked example based on a fictional
5,000-user financial services organisation operating a modern security
estate including cloud, identity, PAM, EDR, SIEM, SOAR, NAC, CASB and
ZTNA capabilities.

The purpose of worked examples is to demonstrate how ORSM moves from
principle to architectural decision.

## Example assessment structure

For each domain record:

1.  the questions asked;
2.  the evidence gathered;
3.  the score assigned;
4.  material findings;
5.  operational risks;
6.  recommendations; and
7.  the resulting architectural decision.
